# BanaVara Platform

کد نسخه فعلی وب‌سایت بناورا و مسیر توسعه سامانه شفاف مدیریت پروژه.

## نسخه موجود

این مخزن شامل نسخه منتشرشده سایت در پوشه `dist/` است.

- وب‌سایت: https://banavara.kooroshsti.chatgpt.site
- زبان رابط: فارسی و راست‌به‌چپ
- حوزه: طراحی، بازسازی و اجرای یکپارچه پروژه‌های مسکونی، ویلایی و تجاری

## ساختار

- `dist/index.html`: صفحه اصلی
- `dist/style.css`: استایل اصلی
- `dist/assessment.html`: ارزیابی اولیه ملک
- `dist/assessment.css`: استایل ارزیابی
- `dist/assessment.js`: منطق فرم ارزیابی
- `.openai/hosting.json`: تنظیمات انتشار فعلی Sites

## اصل توسعه

اول پروژه و مشتری واقعی؛ سپس توسعه سیستم بر اساس نیاز واقعی، با معماری آینده‌دار.
